## 1. 项目概述

### 1.1 项目背景

专用车辆（厢式车、罐车、起重车等）上装设计的图纸审查是一项专业性强、工作量大的任务。传统人工审查存在效率低、标准不统一、易遗漏等问题。

本系统旨在通过**AI大模型 + 传统规则引擎**的混合方案，实现工程图纸的自动审查，提升审查效率和准确性。

### 1.2 核心思路

```
┌─────────────────────────────────────────────────────────────┐
│                    混合审查策略                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  AI优先审查（阶段2）                                         │
│  ├── 优势：快速、理解能力强、能发现经验性问题                  │
│  ├── 输入：图纸截图 + 结构化数据                             │
│  └── 输出：自然语言审查意见                                  │
│                                                             │
│  +                                                            │
│                                                             │
│  规则精确验证（阶段3，可选）                                  │
│  ├── 优势：精确、可复现、符合法规要求                         │
│  ├── 输入：DXF几何数据                                       │
│  └── 输出：精确尺寸校验结果                                  │
│                                                             │
│  =                                                            │
│                                                             │
│  融合审查报告                                                 │
│  └── AI描述 + 规则数据 + 标准引用                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 适用车型

| 车型 | 英文 | 审查重点 |
|------|------|----------|
| 厢式运输车 | Van | 瓦楞结构、插接密封、前板加强 |
| 罐式运输车 | Tank | 封头形式、防波板、支座位置 |
| 随车起重运输车 | Crane | 支腿跨距、吊重曲线、稳定性 |
| 压缩式垃圾车 | Compactor | 压缩机构、密封、污水收集 |
| 混凝土搅拌车 | Mixer | 叶片角度、进出料、残余率 |
| 自卸车 | Dump | 举升机构、副车架强度、锁止 |

## 3. 模块设计

### 3.1 阶段0：数据预处理层（进行中）

#### 3.1.1 DWG Converter Service

**职责**: 将DWG转换为DXF格式

**技术方案**: 调用ODA File Converter命令行

**核心接口**:
```python
class DWGConverter:
    def convert(self, dwg_path: Path) -> ConversionResult:
        """
        DWG转DXF
        返回: 转换结果 + 质量报告
        """
        
    def batch_convert(self, paths: List[Path]) -> List[ConversionResult]:
        """批量转换，带进度回调"""
        
    def validate(self, dxf_path: Path) -> ValidationReport:
        """验证转换质量"""
```

**输出**:
- DXF文件
- 转换日志
- 质量报告（实体保留率等）

#### 3.1.2 PNG Renderer Service

**职责**: 将DXF渲染为高清PNG图片

**技术方案**: matplotlib + Pillow

**核心接口**:
```python
class DXFRenderer:
    def render(self, dxf_path: Path, options: RenderOptions) -> Image:
        """
        渲染DXF为PNG
        默认分辨率: 2048x2048
        """
        
    def render_with_layers(self, dxf_path: Path, 
                          visible_layers: List[str]) -> Image:
        """按指定图层渲染"""
```

**渲染选项**:
- 背景色（白/黑）
- 线宽缩放
- 图层可见性
- 颜色模式（彩色/黑白）

#### 3.1.3 Data Assembler

**职责**: 组装AI审查所需的数据包

**输出数据包结构**:

## 4. 数据模型详细设计

### 4.1 车辆模型

```python
class VehicleType(str, Enum):
    VAN = "van"           # 厢式运输车
    TANK = "tank"         # 罐式运输车
    CRANE = "crane"       # 随车起重运输车
    COMPACTOR = "compactor" # 压缩式垃圾车
    MIXER = "mixer"       # 混凝土搅拌车
    DUMP = "dump"         # 自卸车

class VehicleInfo(BaseModel):
    vehicle_type: VehicleType
    vehicle_type_name: str
    chassis_brand: Optional[str] = None
    chassis_model: Optional[str] = None
    wheelbase: Optional[float] = None
    total_mass: Optional[float] = None
```

### 4.2 结构模型

```python
class Subframe(BaseModel):
    """副车架"""
    longerons: List[Longeron]      # 纵梁列表
    cross_beams: List[CrossBeam]   # 横梁列表
    connectors: List[Connector]    # 连接件列表
    total_length: float
    total_width: float
    total_height: float

class VanBody(BaseModel):
    """厢体"""
    body_type: str                 # 瓦楞板/插接板
    length: float
    width: float
    height: float
    panel_thickness: float

class TankBody(BaseModel):
    """罐体"""
    tank_type: str                 # 圆罐/椭圆罐
    length: float
    diameter: Optional[float] = None
    head_type: str                 # 封头形式
    baffle_count: int              # 防波板数量
```

### 4.3 审查结果模型

```python
class IssueSeverity(str, Enum):
    CRITICAL = "critical"   # 严重 - 必须修改
    WARNING = "warning"     # 警告 - 建议修改
    INFO = "info"           # 提示 - 仅供参考

class IssueCategory(str, Enum):
    STRUCTURE = "structure"     # 结构问题
    REGULATION = "regulation"   # 法规问题
    SAFETY = "safety"           # 安全问题
    PROCESS = "process"         # 工艺问题

class Issue(BaseModel):
    id: str
    severity: IssueSeverity
    category: IssueCategory
    title: str
    description: str
    suggestion: str
    standard: Optional[str] = None
    confidence: float = 1.0

class CheckResult(BaseModel):
    drawing_id: str
    vehicle_type: str
    summary: CheckSummary
    issues: List[Issue]
    passed: bool
    score: float
```
