# 03 - 三维可视化模块

**目标**: 实现 SolidWorks 3D 模型的可视化查看、装配树交互、BOM 数据展示  
**质量基线**: 工程师可直接在浏览器中审查模型结构，无需打开 SW

---

## 一、功能范围

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 装配树可视化 | 层级结构 + 组件属性 | P0 |
| 3D 模型预览 | 简化几何体 / 截图 / 轻量化模型 | P1 |
| BOM 交互表格 | 树形表格 + 筛选 + 导出 | P0 |
| 零件属性卡片 | 材料 / 质量 / 边界盒 | P1 |
| 配合关系图 | 装配约束可视化 | P2 |

## 三、可视化方案

### 3.1 装配树（Step 1-2）

**布局**: 左侧步骤导航中展开，或主画布左侧边栏

```
LB26.00000拉臂总成 [45]
├── LB26.10000底架 [12]
│   ├── LB26.11000底架焊合 ⚙️
│   ├── GB/T 5783 螺栓M12×30 ×4 ⭐
│   └── GB/T 95 平垫圈12 ×4 ⭐
├── LB26.20000翻转架 [8]
│   ├── LB26.21000翻转架焊合 ⚙️
│   └── ...
├── LB26.30000主臂 [10]
│   └── ...
└── LB26.40000前臂 [8]
    └── ...

图例: ⚙️=焊接件 ⭐=标准件 📦=子装配
```

**交互**:
- 点击节点 → 右侧显示零件属性卡片
- 双击节点 → 展开/折叠子项
- 右键 → 菜单（查看3D / 查看图纸 / 导出BOM）
- 复选框 → 批量选择（用于后续生成范围）

### 3.2 3D 预览（Step 1）

**方案对比**:

| 方案 | 实现 | 优点 | 缺点 | 决策 |
|------|------|------|------|------|
| A. SW 截图 | SW API 保存视口图片 | 真实、准确 | 静态、无法交互 | M1 使用 |
| B. Three.js + 简化几何 | Box/Sphere 替代 | 轻量、可交互 | 不精确 | M3 使用 |
| C. Three.js + STEP 加载 | 加载 STEP/OBJ | 精确、可交互 | 文件大、解析慢 | M4 评估 |
| D. 轻量化格式 | 转 glTF/USDZ | 最优 | 需额外转换工具 | 长期 |

**M3 实现**: 方案 B + 方案 A  fallback

```
Three.js 场景:
├── 根节点 (Assembly)
│   ├── 组件1 (BoxGeometry, 颜色=层级色)
│   │   └── 变换矩阵 (来自 SW)
│   ├── 组件2 (BoxGeometry)
│   └── ...
└── 坐标轴辅助 (AxesHelper)

交互:
- OrbitControls: 旋转/缩放/平移
- Raycaster: 点击选中 → 高亮 → 显示属性
- 层级颜色: Level1=红, Level2=绿, Level3=蓝
```

### 3.3 BOM 表格（Step 2）

**组件**: AG Grid 树形表格

| 列 | 说明 | 可编辑 |
|----|------|--------|
| 层级 | 缩进显示 | 否 |
| 图号/名称 | 零件标识 | 否 |
| 类型 | 焊接件/机加件/标准件 | 否 |
| 数量 | 装配数量 | 是（生成时覆盖） |
| 材料 | 牌号+标准 | 是 |
| 单重(kg) | 单个质量 | 否 |
| 总重(kg) | 数量×单重 | 否 |
| 来源 | 自制/外购/标准 | 是 |
| 操作 | 查看/编辑/删除 | - |

**功能**:
- 展开/折叠层级
- 按类型筛选（只看焊接件）
- 排序（按总重降序）
- 导出 Excel
- 与装配树联动（表格行选中 ↔ 树节点高亮）

## 五、后端接口

```yaml
# GET /api/generate/{task_id}/step/1/artifacts
# 获取 Step 1 产物
Response:
  artifacts:
    - id: "snapshot"
      type: "png"
      url: "/api/.../step_1/snapshot.png"
    - id: "assembly_tree"
      type: "json"
      url: "/api/.../step_1/assembly_tree.json"

# GET /api/generate/{task_id}/component/{comp_id}
# 获取零件详情
Response:
  part: PartDetail

# GET /api/generate/{task_id}/bom?format=tree|flat
# 获取 BOM 数据
Response:
  bom: BOMItem[]
  summary:
    total_items: 45
    total_weight: 1256.8
```

## 六、性能要求

| 指标 | 目标 | 优化手段 |
|------|------|---------|
| 装配树渲染 | <500ms (1000节点) | 虚拟滚动 |
| 3D场景帧率 | >30fps (100组件) | LOD + Frustum Culling |
| BOM表格 | <1s (10000行) | AG Grid虚拟滚动 |
| 零件详情加载 | <200ms | 内存缓存 |
| 截图生成 | <3s | 线程池异步 |
