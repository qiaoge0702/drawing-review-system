## 三、启动与停止

### 3.1 启动脚本

```bash
#!/bin/bash
# start.sh

set -e

echo "=== 启动图纸智能系统 ==="

# 1. 环境检查
echo "检查环境..."
python --version
python -c "import win32com.client; print('pywin32 OK')"

# 2. 配置加载
export APP_ENV=production
export CONFIG_PATH=/etc/drawing-system/production.yaml

# 3. 目录初始化
mkdir -p /data/drawing-system/{uploads,output,temp,logs}

# 4. 启动服务
echo "启动 FastAPI 服务..."
exec python -m uvicorn app.main:app \
    --host 0.0.0.0 \
    --port 8000 \
    --workers 2 \
    --log-level info \
    --access-log \
    --proxy-headers
```

### 3.2 停止脚本

```bash
#!/bin/bash
# stop.sh

echo "=== 优雅停止服务 ==="

# 1. 发送优雅停止信号
kill -TERM $(cat /var/run/drawing-system.pid)

# 2. 等待当前任务完成（最多60秒）
timeout=60
while [ $timeout -gt 0 ]; do
    if ! pgrep -f "uvicorn" > /dev/null; then
        echo "服务已停止"
        exit 0
    fi
    echo "等待任务完成... ($timeout秒)"
    sleep 5
    timeout=$((timeout - 5))
done

# 3. 强制停止
echo "强制停止..."
kill -KILL $(cat /var/run/drawing-system.pid)
```

### 4.2 健康检查端点

```python
# /health - 存活检查
@app.get("/health")
async def health():
    return {"status": "ok"}

# /ready - 就绪检查
@app.get("/ready")
async def ready():
    checks = {
        "database": check_database(),
        "storage": check_storage(),
        "sw_com": check_sw_com(),
        "ai_api": check_ai_api(),
    }
    all_ready = all(checks.values())
    return {
        "status": "ready" if all_ready else "not_ready",
        "checks": checks
    }

# /metrics - Prometheus指标
@app.get("/metrics")
async def metrics():
    return generate_prometheus_metrics()
```

## 五、备份策略

### 5.1 备份内容

| 内容 | 频率 | 保留期 | 存储位置 |
|------|------|--------|---------|
| 任务元数据 (SQLite) | 每小时 | 30天 | 本地 + 远程 |
| 生成的DWG/DXF | 实时 | 90天 | NAS |
| 日志文件 | 每日 | 180天 | 对象存储 |
| 系统配置 | 变更时 | 永久 | Git |

### 5.2 备份脚本

```bash
#!/bin/bash
# backup.sh

BACKUP_DIR="/backup/drawing-system/$(date +%Y%m%d)"
mkdir -p $BACKUP_DIR

# 1. 备份数据库
cp /data/drawing-system/tasks.db $BACKUP_DIR/

# 2. 备份生成的图纸
rsync -av /data/drawing-system/output/ $BACKUP_DIR/output/

# 3. 打包压缩
tar czf $BACKUP_DIR.tar.gz $BACKUP_DIR

# 4. 上传到远程存储
aws s3 cp $BACKUP_DIR.tar.gz s3://drawing-system-backup/

# 5. 清理旧备份
find /backup/drawing-system -name "*.tar.gz" -mtime +30 -delete
```

## 六、故障处理手册

### 6.1 常见故障

| 故障现象 | 根因 | 处理步骤 |
|---------|------|---------|
| SW COM 连接失败 | SW未运行/崩溃 | 1.检查SW进程 2.重启SW 3.重启服务 |
| 任务队列堆积 | 生成时间过长 | 1.检查SW状态 2.扩容worker 3.限流 |
| DXF生成失败 | 几何复杂度过高 | 1.降级简化 2.通知用户 3.记录案例 |
| AI API超时 | 网络/限流 | 1.重试 2.切换备用API 3.降级规则库 |
| 磁盘满 | 产物未清理 | 1.清理临时文件 2.扩展存储 3.检查清理策略 |
| 内存溢出 | 大文件处理 | 1.重启服务 2.限制文件大小 3.优化内存 |

### 6.2 应急响应

```
P0 (生产中断)
  ├── 检测: 监控告警自动触发
  ├── 通知: 飞书群 + 短信 + 电话
  ├── 响应: 5分钟内人工介入
  ├── 恢复: 30分钟内恢复服务
  └── 复盘: 24小时内产出报告

P1 (功能降级)
  ├── 检测: 成功率下降
  ├── 通知: 飞书群
  ├── 响应: 30分钟内
  ├── 恢复: 2小时内
  └── 复盘: 72小时内

P2 (性能下降)
  ├── 检测: 延迟升高
  ├── 通知: 飞书群
  ├── 响应: 1小时内
  ├── 恢复: 4小时内
  └── 复盘: 一周内
```
