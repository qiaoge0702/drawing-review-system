# 05 - 生成-审查闭环模块

**目标**: 生成结果自动进入审查，问题可定位到具体步骤，支持人工修正后重新生成  
**质量基线**: 生成→审查→修正→重跑形成完整闭环，不丢数据、不丢上下文

---

## 二、审查接入点

### 2.1 复用现有审查系统

```python
# Step 8 内部实现
class ReviewAdapter:
    """
    将生成结果转换为审查系统可接受的输入格式
    """
    def __init__(self):
        self.dxf_parser = DXFParser()
        self.rule_engine = get_rule_engine()
        self.ai_analyzer = None  # 按需初始化
    
    async def review_generated_dxf(
        self,
        dxf_path: Path,
        original_sw_path: Path,
        generation_params: Dict
    ) -> ReviewResult:
        """
        对生成的DXF执行完整审查
        """
        # 1. 解析DXF
        drawing = self.dxf_parser.parse(dxf_path)
        
        # 2. 规则校验（硬规则）
        rule_issues = self.rule_engine.check_drawing(drawing.to_dict())
        
        # 3. AI审查（软规则）
        # 复用现有 analyzer.py，传入生成参数作为上下文
        dxf_json = drawing.to_json()
        ai_result = await self._call_ai_review(
            dxf_json=dxf_json,
            generation_context=generation_params
        )
        
        # 4. 合并结果
        return ReviewResult(
            rule_issues=rule_issues,
            ai_issues=ai_result.get("issues", []),
            summary=self._generate_summary(rule_issues, ai_result)
        )
```

## 三、问题定位机制

### 3.1 问题分类与步骤映射

| 问题类型 | 典型表现 | 关联步骤 | 定位方式 |
|---------|---------|---------|---------|
| 视图缺失 | 应有的视图未生成 | Step 3 | 检查views列表 |
| 轮廓错误 | 形状与3D不符 | Step 3 | 对比SW截图 |
| 尺寸遗漏 | 关键尺寸未标注 | Step 4 | 检查dimensions列表 |
| 尺寸错误 | 标注值与测量不符 | Step 4 | 关联entity测量 |
| 公差不合理 | 公差等级不匹配 | Step 4 | 检查tolerance.grade |
| BOM遗漏 | 组件未列入 | Step 5 | 对比Step 2 BOM |
| 技术要求不全 | 缺少必要条文 | Step 6 | 检查content列表 |
| 图层混乱 | 实体在错误图层 | Step 7 | 检查layer分配 |
| 图框缺失 | 标题栏不完整 | Step 7 | 检查blocks |
| 比例错误 | 视图比例不当 | Step 3/7 | 检查scale |

## 四、重跑机制

### 4.1 重跑策略

| 重跑范围 | 场景 | 数据保留 |
|---------|------|---------|
| 单步重跑 | 某一步参数调整 | 前序步骤全部保留 |
| 从某步开始 | 前面步骤有依赖变更 | 该步之前保留 |
| 全量重跑 | 源文件变更 | 全部重新生成 |

### 4.2 重跑实现

```python
class PipelineRerunManager:
    """
    管理重跑逻辑，确保数据一致性和上下文保留
    """
    async def rerun_from_step(
        self,
        task_id: str,
        from_step: int,
        parameter_overrides: Dict[str, Any]
    ) -> TaskResult:
        # 1. 加载检查点
        checkpoint = await self.checkpoint.restore(task_id)
        
        # 2. 验证前序步骤完整性
        for step in range(1, from_step):
            artifacts = self._get_step_artifacts(task_id, step)
            if not all(a.verify() for a in artifacts):
                raise RerunError(f"Step {step} 产物不完整，无法重跑")
        
        # 3. 清除目标步骤及后续产物
        for step in range(from_step, 8):
            await self._clear_step_artifacts(task_id, step)
        
        # 4. 应用参数覆盖
        config = self._load_step_config(from_step)
        config.parameters.update(parameter_overrides)
        
        # 5. 执行重跑
        return await self.pipeline.execute_from(task_id, from_step, config)
    
    async def rerun_single_step(
        self,
        task_id: str,
        step: int,
        parameter_overrides: Dict[str, Any]
    ) -> StepResult:
        """
        重跑单步，不影响其他步骤。
        仅适用于无副作用的步骤（如标注位置调整）
        """
        # 验证步骤可独立重跑
        step_config = PIPELINE_CONFIG[step - 1]
        if not step_config.idempotent:
            raise RerunError(f"Step {step} 不支持独立重跑")
        
        # 执行重跑
        return await self._execute_step(task_id, step, parameter_overrides)
```

## 五、人工修正工作流

### 5.1 修正类型

| 修正类型 | 操作 | 持久化方式 |
|---------|------|-----------|
| 标注位置调整 | 拖拽 | 覆盖step_4产物 |
| 公差修改 | 编辑数值 | 覆盖step_4产物 |
| 技术要求编辑 | 文本编辑 | 覆盖step_6产物 |
| BOM行增删 | 表格操作 | 覆盖step_5产物 |
| 图层调整 | 开关/移动 | 覆盖step_7产物 |
| 手动添加实体 | 绘图工具 | 合并到step_7产物 |


## 八、质量检查点

- [ ] 审查结果可定位到具体步骤和实体
- [ ] 重跑后前序步骤产物不被破坏
- [ ] 人工修正有完整记录，可审计
- [ ] 修正可转化为模板/规则，积累知识
- [ ] 闭环延迟 < 5秒（从生成完成到审查就绪）
- [ ] 报告包含完整上下文，可离线查看
- [ ] 签字出图前必须全部问题处理完毕
