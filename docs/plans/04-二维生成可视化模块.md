# 04 - 二维生成可视化模块

**目标**: 实现从 3D→2D 投影、尺寸标注、DXF 构建的全流程可视化  
**质量基线**: 工程师可逐步审查、调整、验证每张图纸的生成质量

---

## 一、功能范围

| 步骤 | 功能 | 可视化内容 | 优先级 |
|------|------|-----------|--------|
| Step 3 | 视图投影 | 多视图2D轮廓 (前/俯/左/剖) | P0 |
| Step 4 | 尺寸标注 | 标注分布、位置、公差 | P0 |
| Step 5 | BOM表 | 图纸内BOM表格预览 | P1 |
| Step 6 | 技术要求 | 文本块、模板变量 | P1 |
| Step 7 | DXF构建 | 图层结构、实体列表、最终图纸 | P0 |

---

### 2.1 数据产出

```json
{
  "views": [
    {
      "name": "front",
      "display_name": "主视图",
      "projection": "first_angle",      // 第一角投影
      "entities": [
        {"type": "line", "x1": 0, "y1": 0, "x2": 100, "y2": 0},
        {"type": "arc", "cx": 50, "cy": 50, "r": 25, "start_angle": 0, "end_angle": 180},
        {"type": "circle", "cx": 50, "cy": 50, "r": 10}
      ],
      "hidden_lines": [...],
      "center_lines": [...],
      "section_hatch": {...},           // 剖面线区域
      "bounding_box": {"min_x": 0, "min_y": 0, "max_x": 100, "max_y": 100},
      "scale": "1:1"
    },
    {"name": "top", "display_name": "俯视图", ...},
    {"name": "left", "display_name": "左视图", ...},
    {"name": "section_a", "display_name": "A-A剖视图", ...}
  ],
  "layout": {
    "sheet_size": "A1",                  // A0/A1/A2/A3/A4
    "orientation": "landscape",
    "view_positions": {                  // 图纸上各视图位置
      "front": {"x": 100, "y": 200, "width": 300, "height": 200},
      "top": {"x": 100, "y": 450, "width": 300, "height": 100},
      ...
    }
  }
}
```

### 2.2 可视化方案

**布局**: 图纸画布 + 视图切换栏

```
┌─────────────────────────────────────────┐
│  [主视图] [俯视图] [左视图] [A-A剖视] [全图] │  ← 视图切换
├─────────────────────────────────────────┤
│                                         │
│         ┌─────────────┐                 │
│         │             │                 │
│         │   主视图     │                 │
│         │             │                 │
│         └─────────────┘                 │
│              ↓                          │
│    ┌─────────────┐  ┌─────────────┐     │
│    │   俯视图     │  │   左视图     │     │
│    └─────────────┘  └─────────────┘     │
│                                         │
│  图例: ─── 可见轮廓  - - - 隐藏线  ─·─ 中心线 │
│                                         │
└─────────────────────────────────────────┘
```

**SVG 渲染规范**:

| 元素 | SVG元素 | 样式 |
|------|---------|------|
| 可见轮廓 | `<path>` / `<line>` | stroke=#000, width=0.5mm |
| 隐藏线 | `<path>` stroke-dasharray | stroke=#666, dash=3,3 |
| 中心线 | `<line>` stroke-dasharray | stroke=#00f, dash=10,3,3,3 |
| 剖面线 | `<pattern>` + `<path>` | 45°斜线, spacing=3mm |
| 视图边框 | `<rect>` | stroke=#ccc, dash, 仅预览显示 |

**交互**:
- 滚轮缩放、拖拽平移
- 点击实体 → 高亮 + 显示属性（长度/半径/角度）
- 视图切换 → 单视图放大 / 全图布局
- 显示/隐藏：轮廓线/隐藏线/中心线/剖面线

## 三、尺寸标注可视化 (Step 4)

### 3.1 数据产出

```json
{
  "dimensions": [
    {
      "id": "dim_001",
      "type": "linear",                // linear | diameter | radius | angle
      "value": 3200,
      "unit": "mm",
      "tolerance": {
        "upper": 0.5,
        "lower": -0.5,
        "grade": "IT14"                // 公差等级
      },
      "position": {
        "x1": 0, "y1": -50,           // 第一条延伸线
        "x2": 3200, "y2": -50,        // 第二条延伸线
        "text_x": 1600, "text_y": -60  // 文字位置
      },
      "associated_entities": ["line_001", "line_002"],
      "is_automatic": true,            // AI生成 or 规则生成
      "confidence": 0.92               // AI置信度
    },
    {
      "id": "dim_002",
      "type": "diameter",
      "value": 13,
      "prefix": "⌀",                   // 直径符号
      ...
    }
  ],
  "placement_score": 0.85,             // 布局质量评分
  "overlaps": [                        // 重叠警告
    {"dim_ids": ["dim_003", "dim_004"], "severity": "warning"}
  ]
}
```

### 3.2 可视化方案

**布局**: 图纸叠加标注层

```
┌─────────────────────────────────────────┐
│  [显示全部] [仅自动] [仅手动] [重叠检查]     │  ← 筛选控制
├─────────────────────────────────────────┤
│                                         │
│    │←──── 3200 ±0.5 ────→│             │  ← 线性标注
│    │                       │             │
│    └───────────────────────┘             │
│                                         │
│         ⌀13 H11                          │  ← 直径标注
│         ───┬───                           │
│            │                              │
│                                         │
│  标注列表:                                │
│  ┌────┬─────────┬──────┬────────┬──────┐ │
│  │ ID │ 类型    │ 值   │ 公差   │ 置信 │ │
│  ├────┼─────────┼──────┼────────┼──────┤ │
│  │001 │ 线性    │ 3200 │ ±0.5   │ 0.92 │ │
│  │002 │ 直径    │ 13   │ H11    │ 0.88 │ │
│  └────┴─────────┴──────┴────────┴──────┘ │
│                                         │
└─────────────────────────────────────────┘
```

**交互**:
- 点击标注 → 图纸高亮对应标注 + 编辑面板
- 拖拽标注文字 → 调整位置（实时保存）
- 编辑公差 → 下拉选择公差等级 / 手动输入
- 删除标注 → 标记为手动删除，记录原因
- 添加标注 → 选择实体 → 选择标注类型 → 放置

**重叠检测可视化**:
- 重叠区域红色高亮闪烁
- 建议位置箭头指示
- 一键自动重新布局

## 七、前端组件结构

```
Step3Panel (视图投影)
├── ViewSelector (tabs)
├── SVGCanvas (图纸渲染)
│   ├── EntityLayer (轮廓线)
   ├── HiddenLineLayer (隐藏线)
│   ├── CenterLineLayer (中心线)
│   └── HatchLayer (剖面线)
└── EntityInfoPanel (选中实体属性)

Step4Panel (尺寸标注)
├── DimensionCanvas (SVG叠加层)
│   ├── DimensionLine (标注线)
│   ├── ExtensionLine (延伸线)
│   └── DimensionText (文字)
├── DimensionList (表格)
│   └── EditableRow
├── OverlapWarning (重叠提示)
└── ToleranceEditor (公差编辑)

Step5Panel (BOM生成)
├── BOMPreview (表格叠加)
└── BOMEditor (编辑面板)

Step6Panel (技术要求)
├── TemplateSelector
├── VariableForm
├── TextPreview
└── ManualEditor

Step7Panel (DXF构建)
├── LayerControl (图层开关)
├── EntitySummary (统计)
├── FullPreview (完整图纸)
└── ActionBar (下载/审查)
```

## 八、质量检查点

- [ ] 视图投影轮廓与SW工程图目视一致
- [ ] 尺寸标注覆盖主要特征（长/宽/高/孔径）
- [ ] 标注无重叠（或重叠<5%且已提示）
- [ ] BOM表与SW提取数据一致率>95%
- [ ] 技术要求符合GB/T标准格式
- [ ] DXF图层结构符合企业规范
- [ ] 生成DXF在AutoCAD中打开无错误
- [ ] 图纸布局符合A0/A1/A2/A3/A4标准
