## 二、开发里程碑

### 里程碑定义

每个里程碑必须通过 **质量门禁** 方可进入下一阶段。门禁标准见第六节。

```
M0 ──→ M1 ──→ M2 ──→ M3 ──→ M4 ──→ M5 ──→ M6
基线   框架    核心    可视化   AI增强   闭环    生产
```

| 里程碑 | 周期 | 核心交付 | 质量门禁 |
|--------|------|---------|---------|
| **M0 基线巩固** | 第1周 | 审查系统稳定运行，生成环境就绪 | 112测试全通过，SW COM连接可靠 |
| **M1 框架搭建** | 第2-3周 | 前后端框架、8步流水线骨架、WS协议 | API契约冻结，流水线可空跑 |
| **M2 核心生成** | 第4-6周 | 几何解析→视图投影→DXF构建端到端 | LB26焊接件生成可打开，结构正确 |
| **M3 可视化完备** | 第7-9周 | 8步每步可查看、可交互、可导出 | 每步中间产物独立可验证 |
| **M4 AI增强** | 第10-12周 | 公差推荐、技术要求模板、布局优化 | 公差准确率>80%，技术要求通过率>90% |
| **M5 审查闭环** | 第13-14周 | 生成结果自动进入审查，问题可回溯 | 闭环延迟<5秒，问题定位到步骤 |
| **M6 生产就绪** | 第15-16周 | 性能优化、监控完备、文档齐全 | 单张图<30秒，内存<4GB，零崩溃 |

## 六、质量门禁（必须严格执行）

### 6.1 代码质量

| 检查项 | 工具 | 标准 |
|--------|------|------|
| 类型检查 | mypy | 零错误 |
| 代码风格 | ruff | 零警告 |
| 单元测试 | pytest | 覆盖率>80%，核心模块>90% |
| API契约 | pydantic | 所有请求/响应严格校验 |

### 6.2 功能质量

| 检查项 | 验收标准 |
|--------|---------|
| SW解析准确性 | LB26装配树组件数量=45，名称匹配率100% |
| BOM一致性 | 生成BOM与SW提取BOM字段一致率>95% |
| DXF可打开性 | 生成DXF在AutoCAD/SW中可正常打开，无报错 |
| 图纸规范性 | 标题栏、比例、材料、图号完整率100% |
| 尺寸覆盖度 | 主要特征（长/宽/高/孔径）100%有标注 |

### 6.3 性能质量

| 检查项 | 验收标准 |
|--------|---------|
| 单张图生成时间 | 焊接件<30秒，装配图<60秒 |
| 内存峰值 | 单任务<4GB |
| 并发能力 | 2任务并行不崩溃 |
| 前端首屏 | <2秒 |
| WebSocket延迟 | 步骤更新<500ms |

### 6.4 生产可靠性

| 检查项 | 验收标准 |
|--------|---------|
| 崩溃恢复 | 任一步骤失败，可重跑该步，不丢失前序结果 |
| 数据持久化 | 中间产物自动保存，服务重启可恢复 |
| 日志完备 | 每步有开始/结束/耗时/错误日志 |
| 监控告警 | 内存/CPU/磁盘/任务队列异常自动告警 |
