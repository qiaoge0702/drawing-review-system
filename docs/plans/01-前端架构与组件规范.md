# 01 - 前端架构与组件规范

**目标**: 构建生产级可视化界面，支撑生成系统8步流程的查看、交互、调试  
**质量基线**: 工业软件级体验，非简易Demo

---

## 一、技术选型决策

### 1.1 框架演进路线

| 阶段 | 技术 | 说明 |
|------|------|------|
| M1-M2 | Vanilla JS + 模块化 | 快速验证，无构建依赖 |
| M3起 | Vue3 + TypeScript + Vite | 组件复杂度上升后的必然选择 |
| 长期 | 可扩展至React/独立桌面端 | 预留架构接口 |

### 1.2 核心依赖

| 依赖 | 用途 | 版本锁定 |
|------|------|---------|
| Vue3 | 组件框架 | 3.4+ |
| TypeScript | 类型安全 | 5.3+ |
| Vite | 构建工具 | 5.0+ |
| Pinia | 状态管理 | 2.1+ |
| SVG.js | 2D图纸渲染 | 3.2+ |
| Three.js | 3D模型预览 | 0.160+ |
| AG Grid | 大数据表格 | 31.0+ |
| TailwindCSS | 样式系统 | 3.4+ |

## 四、状态管理

### 4.1 Pinia Store 结构

```typescript
// stores/generate.ts
interface GenerateState {
  // 任务级状态
  taskId: string | null;
  taskStatus: 'idle' | 'running' | 'paused' | 'completed' | 'error';
  overallProgress: number;
  
  // 步骤级状态
  steps: StepInfo[];
  currentStep: number;
  
  // 当前步骤数据
  currentData: any;
  currentArtifacts: Artifact[];
  
  // 全局设置
  settings: GenerateSettings;
}

interface GenerateSettings {
  autoAdvance: boolean;            // 完成一步自动下一步
  showIntermediate: boolean;       // 显示中间产物
  previewQuality: 'low' | 'medium' | 'high';
  maxConcurrentSteps: number;
}
```

### 4.2 数据流

```
用户操作 → Pinia Action → API调用 → WebSocket更新 → State更新 → 组件重渲染
                ↓
         乐观更新UI → 失败回滚
```

```typescript
type GenerateMessage =
```

## 六、可视化渲染规范

### 6.1 3D渲染 (Three.js)

| 场景 | 技术方案 | 性能要求 |
|------|---------|---------|
| 装配树预览 | 简化几何体(Box) + 层级颜色 | 1000组件@60fps |
| 零件详情 | 加载STEP/OBJ | LOD分级 |
| 选中高亮 | OutlinePass后期处理 | 无闪烁 |

### 6.2 2D渲染 (SVG)

| 场景 | 技术方案 | 性能要求 |
|------|---------|---------|
| 视图投影 | 原生SVG path/line/circle | 10000实体无卡顿 |
| 尺寸标注 | SVG text + line + arrow | 支持拖拽调整 |
| 图层控制 | SVG group + visibility | 开关<100ms |
| 剖面线 | SVG pattern | 填充正确 |

### 6.3 大数据表格 (AG Grid)

| 场景 | 配置 | 性能要求 |
|------|------|---------|
| BOM表 | 树形表格 + 虚拟滚动 | 10000行流畅 |
| 实体列表 | 列过滤 + 排序 | 100000行可接受 |
| 日志 | 虚拟滚动 + 自动追加 | 实时不卡顿 |

## 七、错误处理规范

### 7.1 错误分级

| 级别 | 场景 | 前端表现 |
|------|------|---------|
| 致命 | 服务不可用 | 全屏错误页 + 重试按钮 |
| 严重 | 步骤失败不可恢复 | 步骤标红 + 错误详情 + 联系支持 |
| 警告 | 步骤失败可重跑 | 步骤标黄 + 重跑按钮 + 参数调整 |
| 提示 | 非关键异常 | Toast通知，不阻断流程 |

### 7.2 重试策略

```typescript
interface RetryPolicy {
  maxRetries: number;              // 最大重试次数

  backoffMs: 1000,
```
