## 1. 项目目标（量化）

3D 模型（SolidWorks）→ 生产工程图（SLDDRW/DWG）。
纯手工 2.5-4 小时/张 → **15-30 分钟/张**（含人工约 10 分钟把关），节省 80-90%。
人机协同是设计目标：AI 做判断（尺寸筛选/逐步质检），SW 画一切，人终审。

## 4. 铁律与纪律（全期有效）

1. SW API 原生优先；COM 一律走 sw_com 单线程执行器；**不强杀 SW 进程**
2. API 契约冻结（只加不改）；检查点仅成功步骤写
3. 每里程碑验收第一项：目视对比 LB26 案例图纸
4. 方案审查基线 = 真实样例，不是内部文档
5. 严禁蔓延（≤5 文件/≤200 行）；完全遵循设计，疑问先请示
6. 子代理流水线 dev→tester→reviewer→doc-sync，单向经主代理中转
7. 如实原则：取不到的数据留空+warnings，禁止编造
