### 2.1 生成任务 API

```yaml
# POST /api/generate
# 提交生成任务
Request:
  body:
    file: File                    # SW文件 (.SLDASM/.SLDPRT)
    drawing_type: enum            # total_assembly | sub_assembly | part | weldment

    task_id: string

    queue_position: number

# GET /api/generate/{task_id}
# 获取任务状态
Response:
  200 OK:
    task_id: string
    status: enum                  # queued | running | paused | completed | error
    progress: number              # 0-100
    current_step: number          # 1-8
    steps: StepStatus[]
    created_at: datetime
    started_at: datetime | null
    completed_at: datetime | null
    error: ErrorInfo | null

# GET /api/generate/{task_id}/step/{step_number}
# 获取步骤产物
Response:
  200 OK:
    step: number
    status: enum
    artifacts: Artifact[]
    parameters: Parameter[]       # 可调参数
    logs: LogEntry[]

# POST /api/generate/{task_id}/step/{step_number}/rerun
# 重跑某步骤
Request:
  body:
    parameters: map<string, any>  # 覆盖参数

# GET /api/generate/{task_id}/artifact/{artifact_id}
# 下载/查看产物
# Response: 文件流或JSON

# GET /api/generate/{task_id}/preview
# 获取当前完整预览
Response:
  200 OK:
    svg_url: string | null       # 2D预览图
    png_url: string | null       # 渲染图
```

## 四、并发与资源控制

### 4.1 SW COM 并发控制

```python
import asyncio
from contextlib import asynccontextmanager

class SWResourcePool:
    """
    SW COM 是单线程 Apartment 模型，必须串行访问。
    使用全局锁 + 队列实现安全并发。
    """
    def __init__(self, max_concurrent: int = 1):
        self._semaphore = asyncio.Semaphore(max_concurrent)
        self._queue = asyncio.Queue()
        self._metrics = PoolMetrics()
    
    @asynccontextmanager
    async def acquire(self, timeout: int = 300):
        async with self._semaphore:
            self._metrics.active += 1
            try:
                yield self
            finally:
                self._metrics.active -= 1
    
    async def execute(self, task: SWTask) -> SWResult:
        async with self.acquire():
            # 在线程池中执行COM操作
            loop = asyncio.get_event_loop()
            return await loop.run_in_executor(
                None,  # 默认线程池
                self._run_sync,
                task
            )
    
    def _run_sync(self, task: SWTask) -> SWResult:
        # 同步执行SW COM调用
        pass
```

### 4.2 任务队列

```python
class TaskQueue:
    """
    优先级队列，支持:
    - 优先级调度 (VIP任务优先)
    - 资源预留 (保证至少1个槽位给高优)
    - 任务取消
    - 队列监控
    """
    def __init__(self):
        self._queue = asyncio.PriorityQueue()
        self._tasks: Dict[str, QueuedTask] = {}
        self._cancelled: Set[str] = set()
    
    async def enqueue(self, task: GenerateTask, priority: int = 5) -> str:
        queued = QueuedTask(task, priority)
        await self._queue.put((priority, queued.id))
        self._tasks[queued.id] = queued
        return queued.id
    
    async def dequeue(self) -> Optional[QueuedTask]:
        while True:
            priority, task_id = await self._queue.get()
            if task_id not in self._cancelled:
                return self._tasks.get(task_id)
```

## 七、故障恢复

### 7.1 恢复策略

| 故障场景 | 检测方式 | 恢复策略 |
|---------|---------|---------|
| SW崩溃 | COM异常 | 重启SW进程，重试当前步骤 |
| 步骤超时 | 定时器 | 标记失败，可选重试或跳过 |
| 磁盘满 | 写前检查 | 暂停队列，告警，清理旧产物 |
| AI API限流 | HTTP 429 | 指数退避重试，降级到规则库 |
| 内存不足 | 监控阈值 | 取消低优任务，释放资源 |

### 7.2 检查点机制

```python
class CheckpointManager:
    """
    每步完成后自动保存检查点。
    服务重启后可从检查点恢复。
    """
    async def save(self, task_id: str, step: int):
        checkpoint = {
            "task_id": task_id,
            "completed_steps": list(range(1, step + 1)),
            "timestamp": datetime.utcnow().isoformat(),
            "version": CHECKPOINT_VERSION
        }
        path = self._checkpoint_path(task_id)
        await async_write_json(path, checkpoint)
    
    async def restore(self, task_id: str) -> Optional[Checkpoint]:
        path = self._checkpoint_path(task_id)
        if not path.exists():
            return None
        return Checkpoint.parse(await async_read_json(path))
```
