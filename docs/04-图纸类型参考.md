## 一、总装配图是什么

**总装配图（总图）** 是产品的**第一张图**，回答"**最终装完是什么样**"。

### 与其他图纸的核心区别

| 对比项 | 总装配图 | 部件装配图 | 零件图 |
|-------|---------|-----------|--------|
| **回答什么问题** | 整车/整机什么样 | 某个总成怎么装 | 单个零件怎么加工 |
| **看的人** | 老板、客户、总装工人 | 装配班组长 | 车间操作工、数控编程 |
| **核心内容** | 外廓尺寸、部件位置、接口关系 | 零件清单、装配顺序、配合公差 | 尺寸、公差、材料、热处理 |
| **数量** | 1 张 | 几张~十几张 | 几十~几百张 |
| **比例** | 小比例（1:10, 1:20） | 中比例（1:2, 1:5） | 大比例（1:1, 2:1） |

### 专用车辆上装的典型总图内容

```
┌─────────────────────────────────────────┐
│           整车外廓尺寸                   │
│    长 18000±10 × 宽 2550±5 × 高 4000±5   │
├─────────────────────────────────────────┤
│  底盘 ◄──────────────► 上装              │
│  ┌─────┐  副车架  ┌─────────┐          │
│  │驾驶室├─────────┤  厢体    │          │
│  └─────┘  螺栓连接 └─────────┘          │
│     │           │                      │
│  轮胎位置    举升机构位置               │
│              (最大翻转角 45°)           │
├─────────────────────────────────────────┤
│  技术要求：                              │
│  1. 所有焊缝按 JB/T 5943 执行           │
│  2. 涂装底漆厚度 ≥60μm                  │
│  3. 关键焊缝 100% UT 探伤               │
├─────────────────────────────────────────┤
│  标题栏：图名/图号/比例/材料/签名/日期    │
└─────────────────────────────────────────┘
```

## 二、总装配图可以审查什么

### 必须审查（法规硬指标）

| 审查项 | 标准依据 | 当前系统能否自动审查 |
|-------|---------|------------------|
| 整车长度 ≤ 18m | GB 1589-2016 | ✅ 已能做（外廓尺寸提取） |
| 整车宽度 ≤ 2.55m | GB 1589-2016 | ✅ 已能做 |
| 整车高度 ≤ 4m | GB 1589-2016 | ⚠️ 需结合多视图判断 |
| 侧防护离地间隙 ≤ 550mm | GB 11567 | ❌ 需识别"侧防护"部件 |
| 后防护强度 ≥ 70kN | GB 11567 | ❌ 需计算，无法从图纸直接判断 |

### 应该审查（设计合理性）

| 审查项 | 审查逻辑 | 当前系统能否自动审查 |
|-------|---------|------------------|
| 上装重心位置 | 重心投影在轴距范围内，偏前 5-10% | ❌ 需三维模型，2D 图纸难判断 |
| 副车架与底盘连接数量 | 连接点 ≥ 4 个，分布均匀 | ⚠️ 可识别连接件，但需人工确认 |
| 运动部件极限位置 | 举升/翻转不干涉驾驶室、轮胎 | ❌ 需运动仿真，2D 静态图纸难判断 |
| 维修空间 | 发动机舱、滤芯可触及 | ❌ 需经验判断 |

### 可以辅助审查（一致性检查）

| 审查项 | 审查逻辑 | 实现方式 |
|-------|---------|---------|
| BOM 数量与图纸一致性 | 明细表数量 = 图中实际零件数 | ✅ 可自动（提取 BOM + 计数 INSERT） |
| 材料标注一致性 | 标题栏材料 = BOM 中材料 | ✅ 可自动（字符串比对） |
| 比例一致性 | 标题栏比例 = 实际测量比例 | ⚠️ 需人工确认（图纸可能不按比例画） |
| 图号一致性 | 标题栏图号 = 文件名 | ✅ 可自动 |

## 三、生成标注好的可视化图片

### 当前系统已能做
- DXF → PNG（无标注，纯几何线条）

### 老板想要的（标注版 PNG/PDF）

```
┌─────────────────────────────────────────┐
│  [PNG/PDF 可视化输出]                    │
│                                         │
│  1. 整车外廓尺寸标注（红框+文字）         │
│     ┌─────────────────┐                │
│     │  ←—— 18000mm ——→ │                │
│     │                 │                │
│     │    [厢体]        │                │
│     │                 │                │
│     └─────────────────┘                │
│           ↑ 2550mm                     │
│                                         │
│  2. 问题区域高亮                         │
│     - 超限尺寸 → 红色边框               │
│     - 警告项 → 黄色边框                 │
│     - 通过项 → 绿色边框                 │
│                                         │
│  3. 审查意见气泡                         │
│     [⚠️ 长度超限 200mm，建议缩短]        │
│                                         │
│  4. 关键尺寸列表（侧边栏）               │
│     总长: 18000mm ✓                     │
│     总宽: 2600mm ✗ 超限                 │
│     总高: 3950mm ✓                      │
│                                         │
└─────────────────────────────────────────┘
```

### 实现方案

| 方案 | 技术 | 优点 | 缺点 |
|-----|------|------|------|
| A. matplotlib 叠加标注 | 在现有渲染基础上画矩形+文字 | 快速，与现有系统集成 | 样式较简单 |
| B. ezdxf + 新图层 | 在 DXF 里新增"审查标注"图层，再渲染 | 标注可编辑，专业 | 复杂，需处理块/布局 |
| C. PDF 生成（reportlab） | 矢量图形，可缩放，专业报告 | 高质量，打印友好 | 开发量大 |
| D. HTML/SVG | 网页交互式标注，可点击 | 交互性好，现代 | 需前端开发 |

### 我的建议

**短期（1-2 天）**：方案 A — matplotlib 叠加
- 在现有 `dxf_renderer.py` 基础上，加 `render_with_annotations()`
- 输入：审查问题列表（含坐标）
- 输出：带红/黄/绿框和文字标注的 PNG

**中期（1 周）**：方案 C — PDF 报告
- 用 `reportlab` 生成矢量 PDF
- 包含：图纸缩略图 + 标注 + 审查表格 + 签名区

**长期（按需）**：方案 D — 交互式审查界面
- SVG 渲染图纸
- 点击问题列表 → 高亮图纸对应区域
- 人工确认/驳回/批注
