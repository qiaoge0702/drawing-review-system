# 专用车辆上装设计图纸交付物构成说明

> 本文档描述设计师完成上装设计后，交付给生产工人的完整材料构成。
> 用于指导审查系统的审查范围和数据来源。

---

## 一、图纸类（DWG/DXF 文件）

### 1. 总装配图（总图）

工人拿到的第一张图，说明"最终装完什么样"。关键内容：

| 要素 | 说明 |
|------|------|
| 整车外廓尺寸 | 长×宽×高，标注极限偏差（如 18000±10mm） |
| 上装与底盘连接方式 | 副车架怎么固定到底盘上——螺栓连接还是焊接，位置在哪 |
| 各部件相对位置 | 厢体/罐体/起重机构相对底盘的位置、间隙 |
| 运动极限 | 起重臂最大回转半径、自卸车厢最大翻转角等 |
| 技术要求 | 右下角标题栏上方的文字框，写总体焊接、涂装、检验要求 |
| 标题栏 | 图名、图号、比例、材料、设计/校对/审核/批准签名、日期 |

### 2. 部件装配图

把总图拆开，每个总成一张图。专用车辆上装典型部件：

- **副车架总成**：纵梁 + 横梁 + 连接座，所有上装的基础
- **厢体总成**（厢式车）：前壁、侧壁、顶板、门框、门板
- **罐体总成**（罐车）：筒体、封头、防波板、人孔、进出料口
- **起重机构**（随车吊）：吊臂、支腿、转台、液压缸
- **举升机构**（自卸车）：油缸、三角臂、翻转座

每张部件图包含：装配尺寸、配合公差、焊接符号、明细表（列出该部件所有零件）。

### 3. 零件图

每个需要加工的零件一张图，给车间工人/数控设备用。关键内容：

- **定形尺寸**：确定零件形状的尺寸（长、宽、高、孔径、圆角半径）
- **定位尺寸**：确定孔/槽/凸台相对位置的尺寸
- **尺寸公差**：重要尺寸带公差（如 φ20+0.1），不重要的按 GB/T 1804 一般公差
- **表面粗糙度**：配合面 Ra 6.3，密封面 Ra 3.2，非加工面 Ra 25
- **形位公差**：平面度、平行度、垂直度等
- **材料标注**：标题栏里写 Q345B / Q235B / Q345R 等
- **热处理要求**：如调质、正火，写在技术要求里

### 4. 焊接图 / 焊接组件图

专用车辆上装大量使用焊接结构，焊接图是关键交付物：

- **焊接符号**：标注焊缝形式（角焊、对接焊、塞焊）、焊脚尺寸、坡口角度
- **焊缝位置**：哪些是满焊、哪些是段焊（段长×间距）
- **关键焊缝**：纵梁与横梁连接焊缝、罐体纵环焊缝——需要 100% 探伤

### 5. 管路图 / 液压原理图 / 电气原理图

- **液压原理图**：泵、阀、缸、管路的符号和连接关系
- **管路走向图**：管路实际走向、固定位置、管夹间距
- **电气原理图**：传感器、控制器、执行器接线

## 二、文字材料

### 1. 材料明细表（BOM）

工人领料的依据，通常附在总装配图或部件装配图上，也单独出一份汇总表：

| 件号 | 名称 | 数量 | 材料 | 规格/重量 | 备注 |
|------|------|------|------|-----------|------|
| 01 | 纵梁 | 2 | Q345B | [型钢规格] | |
| 02 | 横梁 | 5 | Q345B | [槽钢规格] | 等间距 |
| 03 | 封头 | 2 | Q345R | DN500 | 外购 |

### 2. 设计说明书 / 计算书

- **强度计算**：纵梁抗弯强度、罐体壁厚计算（GB 150）、螺栓强度校核
- **稳定性分析**：起重车抗倾覆、自卸车举升稳定性
- **选型依据**：液压缸吨位、螺栓等级选择理由

### 3. 通用技术条件

通常在图纸包首页或每张图的技术要求栏中引用：

- **焊接技术条件**：JB/T 5943——焊前准备、焊材选择、焊后清理
- **涂装技术条件**：底漆类型、漆膜厚度、色标
- **检验要求**：焊缝探伤等级、尺寸检验方法

### 4. 检验大纲 / 质量控制点

- **进货检验**：原材料复验（化学成分、力学性能）
- **过程检验**：焊接首件检验、尺寸抽检
- **最终检验**：整车尺寸、密封性试验、功能试验

---

## 三、配套清单

工人领料的另外三张表：

- **外购件清单**：液压泵、液压缸、密封件、电气元件——采购用
- **标准件清单**：GB/T 5782 螺栓、GB/T 6170 螺母、GB/T 97 垫圈——仓库领用
- **外协加工件清单**：需要外包加工的零件（如锻件、铸件）

## 四、DXF 可提取 vs 不可提取

| 交付物 | DXF 里有数据吗 | 审查系统可自动生成预览吗 |
|--------|-------------|----------------------|
| 标题栏信息 | 有（TEXT/MTEXT） | 已实现 |
| 实体统计报表 | 有（实体类型计数） | 已实现 |
| 图纸外廓尺寸 | 有（实体坐标范围） | 已实现 |
| PNG 图纸预览 | 有（实体几何） | 已实现 |
| BOM 明细表 | 有（INSERT + ATTRIB） | 可实现 |
| 尺寸标注汇总 | 有（DIMENSION 实体） | 可实现 |
| 文字内容清单 | 有（TEXT/MTEXT） | 可实现 |
| 焊接符号清单 | 有（LEADER/MLEADER + INSERT） | 可实现 |
| 设计说明书 | 无（独立 Word 文档） | 需另外上传 |
| 计算书 | 无（独立文档） | 需另外上传 |
| 检验大纲 | 无（独立文档） | 需另外上传 |
| 外购件清单 | 无（独立 Excel） | 需另外上传 |
