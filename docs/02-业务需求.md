## 二、图纸类型

### 2.1 按层级分类

| 类型 | 内容 | 比例 | 关键要素 |
|------|------|------|----------|
| **总装配图** | 整机总体结构 | 1:10~1:50 | 外形尺寸、安装接口、技术参数 |
| **部件装配图** | 子系统装配 | 1:5~1:20 | 配合尺寸、BOM、安装要求 |
| **零件图** | 单个零件 | 1:1~1:10 | 全部尺寸、公差、材料、技术要求 |
| **原理图** | 液压/电气 | 无比例 | 管路走向、元件符号、接线关系 |

### 2.2 按加工方式分类

| 类型 | 特征 | 图纸重点 |
|------|------|----------|
| **焊接件** | 多零件拼焊 | 焊缝符号、焊接顺序、探伤要求 |
| **机加件** | 切削加工 | 尺寸公差、形位公差、表面粗糙度 |
| **钣金件** | 折弯成型 | 展开尺寸、折弯半径、孔位 |
| **标准件** | 外购/国标 | 规格型号、数量、标准号 |

## 三、图纸规范要点

### 3.1 标题栏

| 字段 | 说明 |
|------|------|
| 图样名称 | 零件/部件全称 |
| 图号 | 按编码规则，如LB26.11000 |
| 材料 | 牌号+标准，如Q355B/GB/T 1591 |
| 比例 | 视图比例 |
| 重量 | 单件重量（kg） |
| 设计/审核/批准 | 签字+日期 |

### 3.2 技术要求（焊接件示例）

```
1. 焊接应符合GB/T 985.1规定
2. 焊缝质量等级：二级（GB/T 19418）
3. 焊后消除应力处理
4. 未注焊缝尺寸：K=5，连续焊
5. 探伤要求：UT-2级（JB/T 4730）
6. 未注倒角：C2
7. 未注圆角：R5
8. 表面除锈：Sa2.5，涂底漆
```

### 3.3 关键标准

| 标准号 | 名称 | 适用 |
|--------|------|------|
| GB/T 985.1 | 气焊、焊条电弧焊 | 焊接件 |
| GB/T 19418 | 钢的弧焊接头 | 焊缝质量 |
| GB/T 1804 | 一般公差 | 未注尺寸 |
| JB/T 5943 | 工程机械焊接件 | 焊缝探伤 |
| QC/T 52 | 车厢可卸式垃圾车 | 整车性能 |

## 四、AI生成重点

基于上述规范，AI生成需重点关注：

| 优先级 | 内容 | 难度 | 方案 |
|--------|------|------|------|
| P0 | BOM表 | 低 | 直接从装配树提取 |
| P0 | 标题栏 | 低 | 读取3D属性自动填充 |
| P0 | 基础尺寸 | 中 | 特征识别+投影测量 |
| P1 | 焊缝标注 | 中 | 识别焊接边→标注焊缝符号 |
| P1 | 技术要求 | 中 | 模板匹配+变量填充 |
| P2 | 公差推荐 | 高 | 规则库+历史学习 |
| P2 | 布局优化 | 高 | 算法优化 |
