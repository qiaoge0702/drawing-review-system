# 09-审查模块概述

## 10.1 一页纸概述

| 属性 | 说明 |
|------|------|
| **位置** | `app/parsers/`, `app/rules/`, `app/ai/`, `app/renderers/` |
| **状态** | ✅ P0已交付，封存不动 |
| **功能** | AI审查DWG：DXF解析→实体提取→规则校验→AI多模态审查→报告生成 |
| **技术栈** | ezdxf + OpenAI/Kimi API + Pillow |

## 10.2 核心组件

| 模块 | 文件 | 职责 |
|------|------|------|
| parsers | `dxf_parser.py` | DXF解析，多编码回退，损坏恢复 |
| parsers | `entity_extractor.py` | 实体提取（线/圆/弧/文字/尺寸） |
| parsers | `metadata_extractor.py` | 标题栏元数据提取 |
| rules | `dimension_rules.py` | 尺寸规则校验 |
| rules | `bom_rules.py` | BOM规则校验 |
| ai | `analyzer.py` | AI多模态分析（图文结合） |
| renderers | `report_renderer.py` | HTML/PDF报告生成 |

## 10.3 纪律与红线
- **封存不动**: P0已验收，禁止任何修改（含格式化）
- **隔离**: 审查模块与生成模块无交叉依赖

## 10.4 方案B命运
**完全封存**。审查模块审查的是DWG输出结果，与生成路线（DXF/方案B）无关。
