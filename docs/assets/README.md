## 使用建议

1. **切入新项目**: 先看本导航，按场景定位文件
2. **开发某步骤**: 读对应模块手册 + 代码本体（唯一事实来源）
3. **排查问题**: 查手册「纪律与红线」章节
4. **写测试**: 参考08-测试体系 + 既有Fixtures
