**里程碑**: P4 / B-M2  
**范围**: Step 5 BOM生成 + Step 6 技术要求  
**目标**: 图纸中可见原生 BOM 表和 InsertNote 注释

---

## 1. 执行顺序

```
Step 1: 3D模型加载
Step 2: 几何解析
Step 3: 视图投影
Step 7: 图纸收尾（保存中间 SLDDRW）
Step 5: BOM生成 ← 当前设计
Step 6: 技术要求 ← 当前设计
Step 4: 尺寸标注（B-M3）
Step 8: 审查闭环
```

Step 5/6 在 Step 7 之后执行，在已保存的 SLDDRW 上继续插入 BOM 表和技术要求注释。

## 2. Step 5: BOM生成

### 2.1 输入

```python
# Step 2 几何解析产物
{
  "components": [
    {
      "code": "LB26.00001",
      "name": "拉臂",
      "material": "Q345B",
      "mass": 12.5,  # kg
      ...
    }
  ]
}
```

### 2.2 BOM 聚合逻辑

| 逻辑 | 说明 |
|------|------|
| 按代号合并 | 同一图号多实例聚合为一行，数量累加 |
| 外购件识别 | 图号含 GB/T、JB/T、HG/T、Q/ 等前缀标记为外购 |
| 重量计算 | 单件重量 × 数量，保留 3 位小数 |
| 排序 | 装配件（非外购）在前，标准件（外购）在后，同级按图号字典序 |

### 2.3 SW API 调用

```python
# InsertBomTable4 插入 BOM 表
table = drawing.InsertBomTable4(
    anchor_type=3,      # 3 = bottom-right（贴标题栏）
    bom_type=2,         # 2 = indented parts list
    config="",
    template_name="bom-standard.sldbomtbt",
    upper_right_x=x,    # 图纸坐标（米）
    upper_right_y=y,
    anchor_component=None
)

# SetHeaderText 设置表头（7列）
table.SetHeaderText("序号", "代号", "名称", "数量", "材料", "重量", "备注")

# InsertBalloon2 插入球标（按视图）
view.InsertBalloon2(
    item_number,
    x, y,
    balloon_style,
    balloon_size
)
```

### 2.4 输出

```json
{
  "bom": [
    {
      "seq": 1,
      "code": "LB26.00001",
      "name": "拉臂",
      "qty": 2,
      "material": "Q345B",
      "weight": 12.500,
      "note": "",
      "is_external": false
    }
  ],
  "balloons": [
    {
      "view": "front",
      "items": [{"seq": 1, "x": 100.5, "y": 200.3}]
    }
  ],
  "is_aggregate": true,
  "external_parts_count": 3
}
```

## 3. Step 6: 技术要求

### 3.1 输入

```python
# 配置参数
{
  "template_id": "weldment_general",  # 或 "machining_general"
  "tech_variables": {                 # 可选，覆盖默认变量
    "grade": "一级",
    "size": "6"
  },
  "tech_config": {
    "position": {"x": 20, "y": 20, "width": 200, "height": 120},
    "style": {"font_size": 3.5, "line_spacing": 1.5}
  }
}
```

### 3.2 模板系统

| 模板 ID | 适用场景 | 默认变量 |
|---------|----------|----------|
| weldment_general | 焊接件 | grade, size, stress_relief, ndt |
| machining_general | 机加工件 | tolerance_grade, chamfer, fillet, roughness, surface_treatment |

### 3.3 SW API 调用

```python
# InsertNote 插入注释
note = drawing.InsertNote(
    text="",  # 先创建再 SetText
    x=x,      # 图纸坐标（米）
    y=y,
    z=0
)

# SetText 设置多行内容
note.SetText("1. 焊接应符合...\n2. 焊缝质量...")

# SetFont 设置字体
note.SetFont(
    name="宋体",
    size=0.0035,  # 3.5mm（米制）
    bold=False,
    italic=False
)

# SetPosition 定位（左下角）
note.SetPosition(x, y, 0)
```

### 3.4 输出

```json
{
  "tech_requirements": {
    "template_id": "weldment_general",
    "template_name": "焊接件通用模板",
    "content": [
      "1. 焊接应符合GB/T 985.1规定",
      "2. 焊缝质量等级：一级（GB/T 19418）",
      "..."
    ],
    "position": {"x": 20, "y": 20, "width": 200, "height": 120},
    "style": {"font_size": 3.5, "line_spacing": 1.5}
  },
  "available_templates": ["weldment_general", "machining_general"]
}
```

## 5. 前端展示设计

### 阶段产物页 — 表格标签

**BOM 表格**（7 列）：
- 序号（居中）
- 代号（120px）
- 名称（150px）
- 数量（居中，60px）
- 材料（100px）
- 重量（右对齐，80px）
- 备注（100px，外购件显示"外购"标签）

**技术要求文本框**：
- 位置：图框左下角（按后端返回的 position 显示占位示意）
- 样式：等宽字体，行高 1.5，字号 13px

### 外购件高亮

```css

.external-badge {
  background: #fa8c16;
```

## 6. 验收标准

| 检查项 | 标准 |
|--------|------|
| BOM 表 | 图纸中可见，7 列表头正确，聚合行数量正确 |
| 外购件 | 标准件前缀识别正确，高亮显示，"外购"备注 |
| 球标 | 主视图/右视图可见，序号与 BOM 对应 |
| 技术要求 | 左下角文本块可见，模板渲染变量替换正确 |
| 前端 | 表格标签 BOM 数据正确渲染，技术要求文本完整展示 |
| 产物文件 | bom.json / tech_requirements.json 落盘正确 |

## 7. 纪律

- SW API 试探同一环节 ≤2 次，第 3 次停手上报
- 取不到的数据留空 + warnings，禁止编造
- 不强杀 SW 进程，COM 调用走 sw_com 单线程执行器
