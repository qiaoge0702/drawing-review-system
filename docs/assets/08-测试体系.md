## 9.3 核心Fixtures

| Fixture | 说明 |
|---------|------|
| `create_test_dxf` | 创建标准测试DXF（含线/圆/文字/圆弧） |
| `libredwg_dxf` | 真实复杂DXF（含结构损坏），不存在则skip |
| `dxf_with_outliers` | 含异常坐标的DXF（10万+），测试分位数裁剪 |
| `large_dxf` | 1000条直线，性能测试 |

## 9.4 运行纪律

| 场景 | 命令 |
|------|------|
| 小改只跑目标文件 | `pytest tests/unit/test_xxx.py -v` |
| 里程碑全套 | `pytest tests/ -v --tb=short` |
| 跳过SW测试 | `pytest tests/ -v -m "not sw_required"` |
