# 07-前端五层与步骤回放

**位置**: `app/static/generate/js/` (~600行总计)

## 8.1 架构分层

| 文件 | 层级 | 职责 |
|------|------|------|
| `api.js` | 数据层 | REST API封装，唯一HTTP交互点 |
| `store.js` | 状态层 | 单一数据源+订阅通知（未来Pinia雏形） |
| `ws.js` | 通道层 | WebSocket连接管理、自动重连、消息分发 |
| `views.js` | 视图层 | DOM渲染函数（未来Vue组件雏形） |
| `main.js` | 动作层 | 事件绑定+协调各层 |

## 8.2 关键接口与契约

**api.js**:
```javascript
api.createTask(sourceFile, config) → {task_id, status}
api.getTask(taskId) → TaskResult
api.listTasks() → {total, tasks}
api.rerun(taskId, fromStep, overrides)
api.snapshotUrl(taskId, step) → string  // 直接用于<img src>
api.artifactUrl(taskId, step, filename) → string
```

**store.js**:
```javascript
store.get(key) / store.getAll()
store.set(patch)  // 更新并通知订阅者
store.subscribe(fn) → unsubscribe

// 状态结构
{ taskId, task, activeStep, tasks, wsConnected }
```

**ws.js**:
```javascript
ws.connect(taskId)   // 建立连接，自动重连
ws.disconnect()
// 消息处理: step_start/step/finished → 拉取全量任务状态刷新
```

## 8.3 步骤回放组件（P3新增，2026-08-05 重构）

> **⚠️ `renderTimeline`（步骤时间线 Step1-8 卡片）已移除（2026-08-05）**。前端不再展示线性步骤时间线。

**当前形态：阶段页唯一主视图 + 阶段卡内嵌步骤明细折叠区**

```javascript
// 阶段页渲染（唯一主视图）
const STAGE_META = [
  {stage:'import',   name:'导入', steps:['模型加载','几何解析']},
  {stage:'skeleton', name:'骨架', steps:['视图投影','图纸收尾']},
  {stage:'table',    name:'表格', steps:['BOM生成','技术要求']},
  {stage:'dim',      name:'标注', steps:['尺寸标注']},
  {stage:'review',   name:'审查', steps:['审查闭环']},
];

// 阶段卡内嵌「步骤明细」折叠区：快照/耗时/警告/该步版本产物下载
// 前端不显示 "Step N" 编号，只显示中文步骤名
```

**快照路由契约**:
| 场景 | URL |
|------|-----|
| 步骤快照 | `GET /api/generate/{task_id}/steps/{step}/snapshot` |
| 产物下载 | `GET /api/generate/{task_id}/artifacts/{step}/{filename}` |

## 8.5 阶段产物页（P4/B-M2 新增）

**设计目标**: 按执行阶段聚合展示产物，而非线性 Step1-8 列表。

### 阶段分组（显示顺序）

| 阶段 | 包含步骤 | 内容 | 下载（含版本产物） |
|------|----------|------|-------------------|
| 导入 | Step 1, 2 | 模型信息、几何解析摘要 | — |
| 骨架 | Step 3, 7 | 四视图快照 | `step7_skeleton.slddrw` + DWG / PDF / PNG |
| 表格 | Step 5, 6 | BOM 表格、技术要求文本 | `step5_table.slddrw` / `step6_table.slddrw` |
| 标注 | Step 4 | 尺寸标注（B-M3 填充） | `step4_final.slddrw` + 终版 DWG/PDF |
| 审查 | Step 8 | 审查报告 | — |

### 与执行顺序的关系

**执行顺序**（后端流水线）: 1 → 2 → 3 → 7 → 5 → 6 → 4 → 8  
**显示顺序**（前端阶段页）: 按阶段分组，便于用户按产物类型查看

### API 契约（Step 5/6 数据）

```javascript
// Step 5 BOM 数据
api.getStepOutput(taskId, 5) → {
  bom: [
    {seq, code, name, qty, material, weight, note, is_external}
  ],
  is_aggregate: true,
  external_parts_count: number
}

// Step 6 技术要求
api.getStepOutput(taskId, 6) → {
  tech_requirements: {
    template_id, template_name,
    content: ["1. ...", "2. ..."],
    position, style
  }
}
```

### 表单简化

删除字段（后端不再使用）：
- ~~图纸类型~~（drawing_type）
- ~~目标格式~~（target_format）

后端默认输出全格式产物（SLDDRW + DWG + PDF + PNG），前端按阶段提供下载入口。
